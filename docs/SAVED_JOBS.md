# Owned saved job snapshots

Use **Lagre stillingen** after a public advertisement analysis (including a visible source-only fallback). Sign in and save your basic profile first. Give the snapshot a useful title. **Mine stillinger** searches titles and structured facts, reopens preserved source/requirements and deletes an owned snapshot after explicit confirmation. No model request is made by saving or reopening.

The backend stores an immutable owner-scoped JSON snapshot of received text (15,000 characters), title, nb/en analysis, source URL/type, receipt time, requirements/facts and omission count. Quotes are checked against that text. This is not independent proof that a browser excerpt is complete or that a client-supplied source label is authentic. The original link and partial-source caveat remain visible. Equivalent content/analysis reopens the existing snapshot; a changed analysis or source is a separate snapshot. Receipt timestamp alone does not create a duplicate. Source-to-source discovery deduplication is separate future work.

V6, PostgreSQL transactions, verified OIDC issuer/subject and CSRF enforce ownership. Limit: 100 snapshots per profile. Browser input cannot set owner or snapshot ID. Next proxies enforce local same-origin requests, bounded bodies and no-store private responses. No advertisement/claim bodies or cookies enter logs. Deleting a saved job also removes its stored matching result; the employer publication and profile claims are unaffected. Future CV/application references require a separate retention rule before this delete action may remove associated material.
