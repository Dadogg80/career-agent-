# ADR 0046: Logical CV source units and geometric PDF paragraphs

Status: Accepted, 2026-10-14

Blank-line splitting alone can merge PDF profile paragraphs, skills groups and work contributions or separate a wrapped line from its entry context. Extend the ADR 0044/0045 structural work with application-owned logical units; the provider does not define replacement ranges or editable identity.

New CV tailoring generations attach optional `sourceUnits` to `CvTailoringResult` and persist them in the existing immutable result/snapshot JSON, with prompt version `cv-section-wording-v6`. Each unit has a sequential `paragraphIndex`, inclusive `start` and exclusive `end` UTF-16 offsets, kind, editability and optional prior entry-header `contextIndex`. Retain ordered, non-overlapping exact source ranges, every non-whitespace character, complete surrogate pairs, at most 500 units and at most 4,000 UTF-16 code units per unit. Units separate recognized headings, identity/contact, bounded literal entry headers, skills groups, contributions and text paragraphs. Recognized identity, section headings and recognized entry headers are protected from wording changes. Header/context recognition is conservative and bounded; it is not a canonical employment/project graph or proof of factual association.

Reuse the same immutable metadata for AI input, section/passage planning, source display, persisted wording review and exact-range assembly. Withhold proposals against protected units; invalid declarations retain explicit unfinished review and valid supported proposals. Invalid stored metadata fails closed instead of silently regenerating ranges. Absent/null metadata retains the exact legacy paragraph algorithm and saved indexes; no migration or historical source/session rewrite is introduced. Accepted replacements preserve all other original text and whitespace.

For new PDF uploads and explicitly requested original rereading, `ReadablePdfText` sets PDFBox `paragraphStart` to a newline and `dropThreshold` to 3. This preserves geometric paragraph gaps while keeping ordinary wrapped lines together; existing column/gutter safeguards remain. Original bytes and previously saved extracted text are unchanged. An explicit reread can change exact-source freshness and require new tailoring; historical decisions/drafts remain readable. Geometry does not reconstruct template layout or establish exhaustive extraction, semantic recall, ATS compatibility or CV_READY.

Retain the existing one-call approval, full confirmed matching evidence, model defaults, output/request bounds, ownership and revision checks. No extra AI calls or factual promotion. Use focused synthetic/mocked validation with no live calls by default; required Foundation CI remains the publication gate. Frozen-input Gemini/Groq comparison, live project-recall validation and independent semantic/structural/visual actual-file review remain pending.


## Continuity correction — 2026-10-14

A further private two-page check exposed narrow skills rows crossing the midpoint of an otherwise valid gutter. Anchor at the repeated right-column start and retain narrower geometric separation once the column is established; ordinary word gaps still imply a full-width row. Known language/interests/references rows retain their values. Compound conjunction prose does not establish a new undated entry header, and a nonterminal wrapped bullet stays one unit across an internal blank line. Dated/new section headers continue to reset scope. These changes affect new source reading/unit creation, preserving immutable legacy text and stored ranges. Synthetic fixtures cover narrow six-group grids and cross-page employer continuity. This remains conservative reading geometry, not template reconstruction or semantic completeness.
