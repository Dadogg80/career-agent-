# CV PDF fonts

Unmodified DejaVu Sans regular/bold font files, copied from the installed Debian fonts-dejavu-core package. Upstream: https://dejavu-fonts.github.io/ . LICENSE.txt retains the font copyright and distribution notice. Bundling these fonts makes PDFBox output independent of Mac/Linux font installation and supports Norwegian/English text. This is a font resource, not a new executable or JVM/npm library. Missing glyphs fail explicitly instead of silently changing candidate text.
